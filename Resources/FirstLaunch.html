How to install and open Artel

  1. Drag Artel onto the Applications folder in this window.

  2. Open Artel from Applications. macOS replies ““Artel” Not Opened”. Click Done, not “Move to Trash”.

  3. Right after that, open System Settings → Privacy & Security, scroll down to the message about Artel and click Open Anyway. Confirm with your password or Touch ID.

You only need to do this once. After that Artel opens as usual and installs updates by itself, without this step.

Instead of steps 2–3 you can run one command in Terminal:

xattr -dr com.apple.quarantine /Applications/Artel.app

Why. macOS blocks any downloaded app that isn't notarized by Apple, and notarization requires a paid developer account. Artel itself is fine — its source code is open: github.com/UxiT/artel.
